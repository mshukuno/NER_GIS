# GNSS Fundamentals for Accurate Data Collection

Learn how GNSS positioning works, why the same location can produce different coordinates, and how to plan a field workflow that delivers positions you can trust.

[Start Lesson 1](01-gnss-basic.md){ .md-button .md-button--primary }

## What you will learn

By the end of this training, you will be able to:

- Explain how GNSS determines a position
- Identify the main sources of error in GNSS positions
- Distinguish between precision and accuracy, and judge which one your project needs
- Describe how corrections improve positions
- Recognize environments where GNSS struggles and adapt your approach
- Plan data collection so positions can be post-processed later

## Who this is for

- Field data collectors and GIS technicians
- GIS analysts and students who work with field-collected data
- Anyone who needs to know how much to trust a set of coordinates

## Before you start

- Basic GIS concepts: coordinates, coordinate systems, and datums
- No receiver is required to follow the concepts

!!! tip "Suggested approach"

    Work through the lessons in order. Each one builds on the previous, and Lessons 5 to 7 assume you understand the error sources from Lessons 2 to 4.
